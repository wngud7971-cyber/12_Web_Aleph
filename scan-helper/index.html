측정 환경과 데이터 확인
앱에서 측정하면 브라우저 내 PostgreSQL(PGlite)의 임시 메모리 DB를 사용합니다. CSV 전체 행을 나눠 가져오며 원본을 복제하지 않습니다. 가져오기와 인덱스 준비 시간은 스캔 시간에 포함하지 않습니다. 준비 실행 각 1회를 제외하고 순차·일반 인덱스 스캔을 번갈아 실행합니다.

내 PostgreSQL에서 측정하는 방법
학습용 DB의 동일한 SELECT 쿼리를 두 방식으로 실행하고, 실행 계획의 스캔 노드가 실제로 바뀌었는지 확인하세요. 아래는 직접 실행하는 형식 예시입니다. 테이블과 조건을 내 실습에 맞게 바꾸세요.




EXPLAIN (ANALYZE, BUFFERS, TIMING OFF, FORMAT JSON)



SELECT * FROM practice_table WHERE sample_flag = 1;




각 방식으로 여러 번 측정해 실행 시간 또는 JSON 결과를 넣으세요. 여러 JSON 결과는 한 배열에 넣거나 줄바꿈으로 이어 붙일 수 있습니다. 실행 순서를 번갈아 섞고, 캐시·부하·테이블 상태를 같게 유지하세요. 방식별 10회는 논문의 기본 반복 횟수이며 이 앱의 최소 입력은 2회입니다.




JSON은 최상위 Execution Time과 스캔 노드를 읽습니다. Seq Scan / Index Scan 한 종류만 있고 대상 스캔 노드가 하나인 결과만 비교합니다. 병렬 실행·조인·비트맵·인덱스 온리 스캔은 이 비교 범위에 포함하지 않습니다. 버퍼 값은 최상위 Plan 값만 사용해 중복 합산을 피합니다.




ANALYZE는 쿼리를 실제로 실행합니다. 학습용 SELECT를 사용하세요. 실행 시간은 서버 실행 시간이며 화면 표시까지의 전체 응답 시간이 아닙니다. PostgreSQL 공식 문서 ↗

    계산 방법
    



    D = 순차 평균 − 인덱스 평균
    SE = √(s²순차 / n순차 + s²인덱스 / n인덱스)
    



    D > 2SE → 인덱스 우위
    D < −2SE → 순차 스캔 우위
    그 외 → 우위 불분명
    



    s는 표본 표준편차입니다. 논문의 탐색적 판정 기준을 사용하며, 정식 유의성 검정이나 95% 신뢰구간을 의미하지 않습니다.
    



    



    



        
    표시값은 반올림한 값입니다. 판정에는 반올림 전 계산값을 사용합니다.

    회수 횟수의 계산 방법과 범위
    회수 횟수 = 생성 시간 ÷ (순차 평균 − 인덱스 평균), 소수점 올림. 인덱스 우위가 불분명하거나 절약 시간이 없으면 회수 횟수를 제시하지 않아요. 생성 시간은 Worker에서 CREATE INDEX 요청부터 완료까지의 경과 시간이고, 조회 시간은 PostgreSQL Execution Time이므로 합계는 단순 참고 계산입니다. 동일 조회와 시간 차이가 계속 유지된다고 가정하며, 데이터 수정에 따른 유지 비용·CSV 가져오기·통계 준비·통신·화면 표시 시간은 포함하지 않습니다. 논문에서 검증한 회수 기준이나 다른 서버의 예측값이 아닙니다.
